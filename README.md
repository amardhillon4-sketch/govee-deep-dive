# Govee Deep Dive

A brand and creative report on [Govee](https://us.govee.com/). It reads the US store, the 2026 campaign calendar, and the first cards returned by the Meta Ad Library impression sort. Adspy’s likes ranking requires a login, so like counts are not included. Meta does not print impression totals on these commercial cards; the report keeps the page order instead.

## Develop

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy on Vercel

This is a Next.js app. From the project root:

```bash
npx vercel
```

Production:

```bash
npx vercel --prod
```
